## Практические работы

### 1. Скрипт для сборки

Требуется написать скрипт, совместимый с POSIX Shell, который производит сборку некоторого исходного файла. Таким файлом может быть как программа на языке C/C++, так и документ TeX. Скрипт должен:

1. Возвращать информативный код ошибки (скажем, если исходный файл вообще невозможно откомпилировать).
2. Анализировать текст и находить заготовленный комментарий с именем конечного файла. Комментарий должен содержать ключевое слово, например `Output:`.
3. Производить сборку во временном каталоге, созданном при помощи утилиты `mktemp`.
4. Удалять временный каталог при любом исходе работы скрипта, включая обработку сигналов, которые требуют немедленного прекращения работы. Если в ходе сборки создаются промежуточные файлы, они должны оставаться во временном каталоге и удаляться вместе с ним.
5. После завершения работы помещать конечный файл рядом с исходным файлом под именем из распознанного комментария.
